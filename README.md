# Python Expense Tracker

A beginner-friendly Python application to track and analyze daily expenses.

## Features

- Add expenses by category
- Store multiple expenses
- Display all recorded expenses
- Calculate total expenses
- Display expenses in Indian Rupees (₹)

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Basic calculations

## How to Run

Run the following command:

```bash
python expense_tracker.py
